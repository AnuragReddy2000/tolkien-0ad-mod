# Tolkien 0 A.D. Mod

A Tolkien Legendarium total-conversion design and development project for 0 A.D. (Pyrogenesis).

## Documentation

The design documents are organized under [`docs/`](docs/):

- [`docs/overview.md`](docs/overview.md) — project scope and overall direction
- [`docs/design-principles.md`](docs/design-principles.md) — shared gameplay principles
- [`docs/factions/`](docs/factions/) — one design document per faction
- [`docs/implementation-roadmap.md`](docs/implementation-roadmap.md) — recommended path from concept to first playable release

The project keeps the standard 0 A.D. game loop:

- Phase I: Village
- Phase II: Town
- Phase III: City

It adds lore-driven faction asymmetry while preserving familiar resources, production, phases, and RTS counterplay.

## Current status

This is currently a design and planning repository. Engine code, templates, art, and audio will be added as implementation begins.
