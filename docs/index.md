# A familiar strategy game, seen through Middle-earth

This project is an unofficial, fan-made total conversion for [0 A.D.](https://play0ad.com/). It keeps the game's familiar economy, three phases, unit production, and counterplay, while giving each civilization a different reason to build, fight, and expand.

You do not need to know Tolkien's history to follow the designs. Each civilization page introduces who the people are, where they fit in the setting, and how that context becomes a readable strategy-game identity.

## Current status

Five civilizations are selectable in the current mod data: **Doriath, Lindon, Mordor, Moria, and Númenor**. They are still under development and are not presented as a fully balanced release. The other seven civilizations are design concepts, not playable factions in the current build.

The mod targets **0 A.D. Release 28 (0.28.0)**. Players testing the same game need the same mod version enabled.
