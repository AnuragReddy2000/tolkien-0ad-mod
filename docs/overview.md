# Project Overview

## Vision

Create a playable Tolkien-inspired total conversion for 0 A.D. that feels like 0 A.D. first and the Legendarium second: familiar phases, resources, production, and counterplay enriched by strong cultural and regional identities.

## Scope

The initial design covers twelve faction concepts:

- Lindon
- Doriath
- Lothlórien
- Moria
- Erebor
- Iron Hills
- Númenor
- Rohan
- Gondor & Arnor
- Harad & Umbar
- Mordor
- Angmar

The first playable release should use a smaller group of factions, then expand once the core systems are stable.

## Design priorities

1. Preserve the normal 0 A.D. phase and resource loop.
2. Give each faction one clear identity and one primary mechanic.
3. Make strengths conditional and weaknesses meaningful.
4. Prefer local, readable effects over permanent global buffs.
5. Keep hero and wonder mechanics powerful but answerable.
6. Reuse established 0 A.D. systems whenever possible.
7. Build a playable vertical slice before attempting full content coverage.

## Current design status

The faction concepts have completed a first balancing and identity review. The next step is implementation planning: selecting the first playable factions, defining shared templates, and identifying which mechanics require scripts or engine support.
