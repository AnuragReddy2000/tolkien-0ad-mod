# Unit Roster Planning

This document defines the next implementation layer beyond faction identity and signature mechanics: actual unit rosters with roles, costs, and special quirks. The first pass is intentionally approximate and structured for balancing before XML implementation.

## Shared roster template

Each unit entry should define:

- Name
- Role
- Cost (Food/Wood/Stone/Metal)
- Population
- HP
- Speed
- Attack type
- Range
- Armor
- Special quirks / abilities
- Counterplay
- Notes

## First playable faction set

1. Lindon
2. Doriath
3. Rohan
4. Mordor
5. Moria
6. Gondor & Arnor

## Intent

These six factions cover the major design pillars:

- elite infantry and navy
- stealth and concealment
- cavalry mobility
- mass industrial pressure
- subterranean durability
- branching defensive/ranger identity

The first roster pass is meant to produce a balanced, working baseline for the first public vertical slice.
