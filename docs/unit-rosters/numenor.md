# Númenor Unit Roster

For current numeric profiles, shared balance rules, and implementation status,
see the [canonical unit-balance specification](../balance/unit-balance.md).
This page records roles only; it is not a second balance target.

| Unit | Template | Role |
|---|---|---|
| Númenórean Worker | `support_worker` | Civilian worker |
| Númenórean Scout | `cavalry_scout` | Light scout cavalry with a spear and anti-cavalry bonus |
| Númenórean Recruit | `infantry_recruit` | Basic sword infantry |
| Númenórean Spearman | `infantry_spearman` | Basic anti-cavalry infantry |
| Númenórean Archer | `infantry_archer` | Standard ranged infantry |
| Númenórean Guard | `infantry_guard` | Hold-line infantry |
| Great Coast Guard | `infantry_coast_guard` | Coastal support infantry |
| Númenórean Champion | `champion_infantry` | Elite melee infantry |
| Númenórean Royal Guard | `infantry_guard_king` | Elite anchor |
| Steel-bow Archer | `champion_archer` | Long-range champion archer |
| Warship, Juggernaut, Siege Ship, Fishing Boat, Trading Ship | `ship_*` | Naval combat, fishing, and trade |
| Steel-Bow Ballista | `siege_ballista` | Long-range precision siege |
| Elendil, Isildur, Ar-Pharazôn | `hero_*` | Command, melee, and naval heroes |

Númenor fields scout cavalry only: no shock or champion cavalry. Its
implemented civilization bonuses include +10% House population and +5%
infantry health. See the canonical balance specification for their present
status and the planned holistic comparison.
